# Références de conception et limites

Sources publiques consultées lors du cadrage ; leurs descriptions ne certifient pas les pratiques d'un futur client. Les données du fixture sont inventées pour recette et ne proviennent d'aucun domaine. Le pack ne reproduit pas les règles juridiques intégrales et ne fournit aucun conseil de vinification.

- Olivier Leflaive — parcours blancs/rouges, approche parcellaire, élevage et décisions par dégustation : https://olivier-leflaive.com/vinification
- Château d'Armailhac — lots séparés, contenants, assemblage et coexistence de millésimes : https://www.chateau-darmailhac.com/fr/chai/
- Château Fonréaud — élevage, assemblage et temporalité de mise différente : https://www.vignobles-chanfreau.com/histoire-chateau-fonreaud-chanfreau/chateau-fonreaud-vignoble
- Comité Champagne — différences de fermentation et choix de la FML ; Champagne cité comme variante, exclu du premier produit : https://www.champagne.fr/fr/decouvrir-le-champagne/elaboration-du-champagne/la-fermentation
- FranceAgriMer — patrimoine/renouvellement et autorisations : https://www.franceagrimer.fr/aides/autorisation-de-plantation-de-vigne
- Douane — registres, opérations et délais : http://www.douane.gouv.fr/demarche/tenue-des-registres-viti-vinicoles
- ISACUVE — périmètre public de suivi vinification/élevage/mise/traçabilité : https://www.isagri.fr/logiciels/isacuve-web-logiciel-de-suivi-de-cuverie
- Cap Vignes — périmètre ERP production/cuiverie/commerce/finance : https://cap-vignes.vin/producteurs-de-vins-et-spiritueux

Documentation du format Copilot :
- https://code.visualstudio.com/docs/copilot/customization/agent-skills
- https://code.visualstudio.com/docs/copilot/customization/prompt-files

Ne pas traiter arguments commerciaux d'éditeur comme garanties indépendamment vérifiées. Actualiser toute règle réglementaire et tout format de plateforme avant passage au réel. Aucun modèle n'est fixé dans les fichiers ; sélectionner un modèle disponible dans l'outil utilisé.

Documentation Antigravity — emplacement des skills et règles :
- https://antigravity.google/docs/ide/skills/
- https://antigravity.google/docs/rules

Le pack utilise les conventions communes AGENTS.md et .agents/skills pour un projet neuf. Vérifier la découverte dans la version installée de l'outil ; le prompt de démarrage demande leur lecture explicite.
